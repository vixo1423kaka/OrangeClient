Czcionka menu: Instrument Sans (SIL Open Font License 1.1, licencja w OFL-InstrumentSans.txt).
Czysty neo-grotesk, wygladem zblizony do SF Pro - mozna ja legalnie rozpowszechniac razem z modem.

ui.ttf       - zwykly tekst
ui_bold.ttf  - pogrubiony tekst (naglowki)

Dopasowanie w ui.json / ui_bold.json:
  size   - wielkosc liter (9.0 = podobna do vanilli)
  shift  - [x, y] przesuniecie, np. [0.0, -1.0] podnosi tekst o 1 px

Chcesz inna czcionke? Podmien ui.ttf / ui_bold.ttf (musza zostac te nazwy).
